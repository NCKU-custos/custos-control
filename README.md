# custos-control

Pixhawk bridge (uXRCE-DDS or MAVROS — see ADR) and mission management for the Custos drone stack.

Depends only on [`custos-interfaces`](https://github.com/NCKU-custos/custos-interfaces) for the wire contract.

For the system overview, see [`custos-bringup`](https://github.com/NCKU-custos/custos-bringup).
